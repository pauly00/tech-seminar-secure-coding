SQL
01. SQL Injection

사용자 입력이 SQL 쿼리에 직접 삽입되면 쿼리 구조를 변조해 인증 우회와 데이터 탈취가 가능

시연 내용
  • 로그인 우회: admin' --
  • UNION SELECT로 전체 계정 정보 추출
방어 방법
  • PreparedStatement 파라미터 바인딩
XSS
02. XSS (Cross-Site Scripting)

악성 스크립트가 페이지에 삽입되어 다른 사용자의 브라우저에서 실행된다.
쿠키 탈취, 피싱 등에 악용

시연 내용
  • Stored XSS: DB 저장 후 모든 사용자에게 실행
  • Reflected XSS: URL 파라미터 즉시 출력
방어 방법
  • 출력 시 HTML 인코딩 (th:text vs th:utext)
FILE
03. 파일 업로드 취약점

확장자, 내용 검증 없이 파일을 허용하면 웹쉘 업로드를 통한 원격 코드 실행(RCE)이 가능

시연 내용
  • webshell.jsp 업로드 후 서버 명령 실행
  • ZIP Slip: 압축 해제 경로 탈출
방어 방법
  • 화이트리스트 확장자 검사 + UUID 파일명
  • ZIP: normalize() + startsWith() 경로 검증
PATH
04. 경로 순회 (Path Traversal)

../를 이용해 허용된 디렉토리 밖의 파일을 읽어 서버 설정, 소스코드, 민감 정보를 노출

시연 내용
  • ../../application.properties로 DB 비밀번호 노출
  • ../../../etc/passwd (Linux 환경)
방어 방법
  • normalize() 정규화 + startsWith(basePath) 검증
