경로 순회 (Path Traversal)

../ 를 이용해 허용된 디렉토리 밖의 파일에 접근하는 취약점입니다.

OWASP A01: Broken Access Control CWE-22
현재 기준 디렉토리: ./safe-files
이 디렉토리 안의 파일만 읽어야 합니다. ../ 로 탈출하는 공격을 시도해보세요.
공격 예시 (기준 경로 밖 파일 읽기):
  • 서버 설정: ../src/main/resources/application.properties
  • Windows: ../../../Windows/win.ini
  • Linux: ../../../etc/passwd
  • 상위 이동: ../../pom.xml
정상 파일:
  • readme.txt
  • info.txt
[취약] 검증 없는 파일 읽기
  • 입력값을 그대로 경로에 붙임
  • ../를 통해 상위 디렉토리 탈출 가능
파일 내용 노출: 

                    

                


                

                    실제 코드 (PathTraversalController.java):
                    

                        
                        
// 취약: 입력값을 그대로 경로에 붙임
String requestedPath = safeFilesDir + "/" + filename;
Files.readString(Path.of(requestedPath));

                    

                

            

        


        
        

            

                

                    
[안전] normalize + 경로 검증

                

                

                    방어 원리:

                    1. normalize() 로 ../ 제거

                    2. startsWith(basePath) 로 기준 경로 이탈 감지

                    3. 이탈 시 접근 거부
                

                

                    

                        
                        
                    

                


                

                    

                    

                        공격 차단!

                        
                    

                    

                        
정상 파일 읽기 성공:

                        

                    

                


                

                    실제 코드 (PathTraversalController.java):
                    

                        
                        
// 안전: normalize + startsWith 검사
Path basePath = Path.of(safeFilesDir).toAbsolutePath().normalize();
Path requestedPath = basePath.resolve(filename).normalize();

if (!requestedPath.startsWith(basePath)) {
    return "경로 순회 공격 감지! 접근 거부";
}
Files.readString(requestedPath);
