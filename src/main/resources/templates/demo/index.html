웹 보안 취약점 데모

각 취약점을 직접 실습하고, 안전한 코드와 취약한 코드를 나란히 비교해보세요.

SQL

SQL Injection

사용자 입력값이 SQL 쿼리에 직접 삽입될 때 발생하는 취약점.

  • 로그인 우회: admin' --
  • UNION 공격으로 계정 정보 탈취
  • 방어: PreparedStatement / 파라미터 바인딩
OWASP A03: Injection
XSS

XSS (Cross-Site Scripting)

악성 스크립트가 웹 페이지에 삽입되어 다른 사용자의 브라우저에서 실행되는 취약점.

  • Reflected XSS: 입력값 즉시 출력
  • Stored XSS: DB 저장 후 모든 사용자에게 실행
  • 방어: HTML 인코딩 (th:text)
OWASP A03: Injection
FILE

파일 업로드 취약점

확장자/내용 검증 없이 파일 업로드 허용 시 웹쉘 등 실행 파일 업로드 가능.

  • webshell.jsp 업로드 → 원격 명령 실행
  • 이중 확장자 우회: image.jpg.jsp
  • 방어: 화이트리스트 + 랜덤 파일명
OWASP A04: Insecure Design
PATH

경로 순회 (Path Traversal)

../를 이용해 허용된 디렉토리 밖의 파일에 접근하는 취약점.

  • ../../application.properties (DB 비밀번호 노출)
  • ../../../etc/passwd (Linux)
  • 방어: normalize() + startsWith() 검사
OWASP A01: Broken Access Control
