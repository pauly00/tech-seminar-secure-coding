파일 업로드 취약점

확장자 검사 없이 파일 업로드 허용 시 웹쉘 업로드 및 ZIP Slip을 통한 임의 파일 쓰기 가능

기본 파일 업로드 (확장자 검사)
[취약] 검증 없는 업로드
  • 확장자 검사 없음 (.jsp, .groovy, .sh 모두 허용)
  • 원본 파일명 그대로 저장 (경로 예측 가능)
원본 파일명:
저장 경로:
FileService.java:
// 원본 파일명 저장 String originalFilename = file.getOriginalFilename(); Path dest = dir.resolve(originalFilename); Files.copy(file.getInputStream(), dest, REPLACE_EXISTING);
[안전] 화이트리스트 검증
허용 확장자: jpg, jpeg, png, gif, pdf, txt, docx, xlsx, zip
방어 원리: 화이트리스트 + UUID 랜덤 파일명
원본:
저장(랜덤):
FileService.java:
// 화이트리스트 if (!ALLOWED_EXTENSIONS.contains(extension)) { return "허용되지 않은 파일 형식"; } // UUID 파일명 String savedName = UUID.randomUUID() + "." + extension; file.transferTo(dir.resolve(savedName).toFile());

ZIP Slip (압축 해제 경로 탈출)

    

        ZIP 내 파일 경로에 ../를 포함시키면 압축 해제 시 서버 임의 경로에 파일을 덮어쓸 수 있음.
        화이트리스트로 .zip을 허용해도 이 공격은 여전히 가능함
    


    

        악성 ZIP 생성 (Python):
        
import zipfile

zf = zipfile.ZipFile('zipslip.zip', 'w')
zf.writestr('../../uploads/pwned.txt', 'ZIP Slip 성공')
zf.writestr('normal.txt', '정상 파일')
zf.close()

        위 스크립트로 zipslip.zip 생성 후 아래 취약 업로드에 올려보세요

[안전] normalize + startsWith 검증

                

                

                    방어 원리:

                    1. normalize()로 ../ 제거

                    2. startsWith(extractDir)로 탈출 감지

                    3. 탈출 시도 엔트리는 건너뜀
                

                

                    

                        
                    

                    
                


                

                    

                        

                        

                            허용된 파일:
                            

                        

                        

                            차단된 엔트리:
                            

                        

                    

                


                

                    FileService.java:
                    
// normalize + startsWith
Path dest = extractDir.resolve(entry.getName()).normalize();
if (!dest.startsWith(extractDir)) {
    continue; // 경로 탈출 차단
}
Files.copy(zis, dest, REPLACE_EXISTING);
