SQL Injection

사용자 입력이 SQL 쿼리에 직접 삽입되면, 쿼리 구조 자체를 변조할 수 있습니다.

OWASP A03:2021 - Injection CWE-89
게시글 검색 SQL Injection
[취약] 문자열 직접 삽입
공격 예시:
  • 전체 조회: %' OR '1'='1
  • 계정 탈취: %' UNION SELECT 1,user_id,user_password,user_name,user_email,user_gender,0 FROM user_tb --
실제 코드 (BbsService.java):
String sql = "SELECT * FROM user_bbs WHERE bbs_title LIKE '%" + keyword + "%'";
[안전] PreparedStatement 바인딩
방어 원리: ? 파라미터 바인딩으로 입력값이 SQL 구조가 아닌 데이터로만 처리됨
실제 코드 (BbsService.java):
String sql = "SELECT * FROM user_bbs WHERE bbs_title LIKE ?"; jdbcTemplate.queryForList(sql, "%" + keyword + "%");
로그인 SQL Injection (인증 우회)
[취약] 문자열 연결 로그인
공격 예시:
  • 비밀번호 없이 admin 로그인: ID=admin' -- PW=아무거나
  • 첫 번째 계정으로 로그인: ID=' OR '1'='1' --
실제 코드 (UserService.java):
String sql = "SELECT * FROM user_tb WHERE user_id = '" + userId + "' AND user_password = '" + password + "'";
[안전] PreparedStatement 로그인
방어 원리: admin' -- 를 입력해도 문자열 리터럴로만 처리되어 우회 불가
실제 코드 (UserService.java):
String sql = "SELECT * FROM user_tb WHERE user_id = ? AND user_password = ?"; jdbcTemplate.queryForList(sql, userId, password);
