XSS (Cross-Site Scripting)

악성 스크립트가 페이지에 삽입되어 다른 사용자 브라우저에서 실행됨

Stored XSS (저장형)

입력값이 서버에 저장되어 이후 모든 사용자 조회 시 실행됨

[취약] th:utext (HTML 그대로 출력)
공격 예시:
  • 경고창: <script>alert('XSS!')</script>
  • 쿠키 탈취: <script>fetch('/demo/steal?c='+document.cookie)</script>
  • 탈취 결과: /demo/steal
  • 이미지 태그: <img src=x onerror="alert('XSS')">
댓글 목록:
댓글 없음
xss.html:
<span th:utext="${comment}"></span>
[안전] th:text (HTML 인코딩)
방어 원리: th:text는 HTML 특수문자를 자동 인코딩
<script> → &lt;script&gt; (표시만 됨, 실행 안 됨)

xss.html:
<span th:text="${comment}"></span> // th:text: 인코딩 후 출력
Reflected XSS (반사형)

입력값이 저장 없이 즉시 응답에 반영되어 URL로 배포됨

[취약] 반사형 XSS
URL 예시:
/demo/xss/reflected?name=<script>alert(1)</script>
